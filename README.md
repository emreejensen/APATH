Web Development APATH Project


The APATH project is a mock website intended to facilitate travel communications between international students and volunteer families, 
while being managed by website administrators. 
This site was created using PHP, HTML, and CSS, including a MySQL database connection to store APATH users and their information.

Phase 1
1. Add Sign Up / Registration Page
2. Create apath_users table in database
3. Add Login Page
4. Add Student Navigation System Pages
5. Add Volunteer Navigation System Pages
6. Add Admin Navigation System Pages

Phase 2
1. Create apath_student table in database
2. Create apath_volunteer table in database
3. Add "Managing Students" page for admin
4. Add edit and delete pages for admin

Phase 3
1. Create PICKUP table
2. Add "Check Pickup Needs" page for volunteers
3, Add "Assign Pickup Volunteers" page for admin

Phase 4
1. Add "Pick Up Information" for students
2. Add "Pick Up Assignment" for volunteers
3. Add About Page
4. Add Contact Page
5. Finalize CSS & Web Design
